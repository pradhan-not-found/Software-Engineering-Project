# Employee Management System — Feature List

## 1. Core HR Features (Table Stakes)
These are expected by default — every competitor has them, so they need to be solid but aren't the differentiator.

- **Onboarding**
  - Digital offer letter & document collection
  - Auto-generated onboarding checklist per role
  - Asset allocation (laptop, ID card, access cards)
  - Welcome workflow (buddy assignment, intro emails)
- **Employee Directory & Profiles**
  - Org chart view
  - Role, department, reporting manager
  - Contact info, documents, certifications
- **Attendance & Time Tracking**
  - Clock in/out, biometric or app-based
  - Shift management
  - Timesheet approvals
- **Leave Management**
  - Leave requests & approvals
  - Leave balance tracking
  - Holiday calendar
- **Payroll**
  - Salary structure & payslip generation
  - Tax deductions, compliance
  - Reimbursements & expense claims
- **Performance Management**
  - Goal setting (OKRs/KPIs)
  - Review cycles (self, peer, manager)
  - Feedback & ratings
- **Offboarding**
  - Exit checklist
  - Asset return tracking
  - Final settlement workflow

---

## 2. Work Management Features (The Differentiator Layer)
Standard project/task tools, but designed to plug directly into HR data — not bolted on separately.

- **To-Do Lists**
  - Personal daily/weekly task lists
  - Recurring tasks
  - Priority tagging
- **Kanban Boards**
  - Team & individual boards
  - Custom workflow stages
  - Drag-and-drop task movement
- **Project/Task Assignment**
  - Assign tasks tied to org structure
  - Deadlines & reminders
  - File attachments & comments per task

---

## 3. Connected Features (The Real Wedge)
This is where the product stops being "just another HRMS + task tool" and becomes something genuinely different — because HR data and work data live in the *same* system.

- **Onboarding → Auto-Generated Kanban Board**
  - New hire joining triggers a pre-built board (IT setup, manager tasks, buddy tasks, employee tasks) — no manual checklist creation.
- **Leave → Task Reassignment Signals**
  - Employee goes on leave → their active tasks get flagged ("delayed — on leave") or suggested for reassignment automatically.
- **Org Chart → Task Permissions**
  - Who can assign/view tasks for whom is inherited from the reporting hierarchy — one permission system, not two.
- **Performance Reviews → Real Task Data**
  - Reviews are pre-populated with actual data: tasks completed, deadlines met/missed, project involvement — instead of being written from memory.
- **Attendance → Workload Context**
  - Managers see task load next to attendance/leave data when planning sprints or approving leave requests.
- **Cross-Module Notifications**
  - A single activity feed where HR events (leave approved, new joiner, review due) and work events (task assigned, deadline near) show up together.

---

## 4. Guiding Principle
> Don't try to out-build dedicated project management tools (ClickUp, monday.com) on depth.
> Win on **2–3 tight, genuinely useful connections** between HR and work data — that's what's hard to copy and easy to explain to a buyer.
